Agent Bus · Phone setup

Let your agents text and call you

When something is urgent, your agents text you. When it is really urgent, your phone rings and a voice reads you the problem. Setup takes about 30 minutes and costs about US$2 a month.

What you get

PriorityWhat happens on your phone
1 – 3 (normal)ntfy notification, same as now.
4 (urgent)ntfy notification + a text message (SMS).
5, or "call me" (very urgent)ntfy notification + a text + a phone call that reads the message out loud.

The call

"Urgent alert from your agents. Pecunia prod is down. Health check failing for 6 minutes… Press 1 to acknowledge. Press 2 to snooze for 10 minutes. Press 3 to hear it again."

1got it2snooze 10 min3repeat

If you don't pick up or don't press a key, it calls once more 3 minutes later. If you miss the call, call the number back to hear the alert.

The text

[Agent Bus] URGENT: Pecunia prod is down
Reply 1 = got it, 2 = snooze 10 min.

Replying 1 to the text works like pressing 1 on the call: the call-back is cancelled and the agent is told you saw it. In class? Just text back 1.

Calls get through even while you're "studying" or "sleeping" on the bus. Agents are told to use them only for real emergencies.

Before you start

  • Your PC, your phone, and a credit card (Twilio needs a US$20 prepaid top-up).
  • About 30 minutes.
  • Never paste a key or token into chat or the bus. The setup command asks for them on your PC, and they go straight to Cloudflare.
1

Cloudflare: free, holds your keys

~5 min

A small free Cloudflare app is the go-between that places your calls and texts. Your PC never stores the Twilio keys.

  • Make a free account at dash.cloudflare.com and verify your email.
  • In the dashboard, open Workers & Pages once. If it asks you to pick a workers.dev subdomain, pick any name (e.g. cameron).
  • On the PC, in PowerShell:
cd C:\Users\camer\Desktop\Projects\notifications\gateway npx wrangler login
  • A browser opens: click Allow. Close it when it says you're logged in.
2

Twilio: places the calls and texts

~10 min
  • Sign up at twilio.com/try-twilio and verify your email and your cell number.
  • Turn on two-factor authentication (your profile → User settings).
  • Upgrade the account: Billing → Upgrade, add a card and pay the US$20 minimum. A trial account plays a Twilio notice and makes you press a key before every call.
  • Leave auto-recharge OFF. The $20 lasts many months.
  • Type "Geo permissions" in the Console search. For Voice and for Messaging, allow Canada only and turn the rest off. This blocks toll fraud.
  • On the Console home page, find Account Info. Keep the tab open: step 3 asks for the Account SID (starts with AC) and the Auth Token (click to reveal).

Don't buy a phone number yourself. Step 3 finds a London-area number (519/226/548) and buys it after you type y.

4

Let the calls through on your phone

~3 min
  • Save the new Twilio number as a contact named Agent Bus. Saved numbers aren't flagged as spam or silenced as unknown callers.

iPhone

  • Contacts → Agent Bus → Edit → Ringtone → turn on Emergency Bypass. It rings even on silent or in a Focus.
  • Optional: Settings → Focus → (Sleep / Do Not Disturb) → People → allow Agent Bus.

Android

  • Star the Agent Bus contact.
  • Settings → Do Not Disturb → People / Calls → allow starred contacts.
5

Test it

~2 min

In the notifications folder, as in step 3:

python notify.py phone test # a test text python notify.py phone test --call # a test call python notify.py phone status # is everything connected?
6

Optional: let the planner call you too

~3 min
python notify.py gateway add-client planner
  • It prints two lines, PHONE_GATEWAY_URL=… and PHONE_GATEWAY_TOKEN=…. Put them in the planner server's environment yourself (SSH in, add them to its env file, restart it).
  • The token is shown once and not saved on the PC. If you lose it, run the command again to make a new one.

If something's off

ProblemFix
Setup says "log in"cd …\notifications\gateway then npx wrangler login, then rerun setup phone.
Setup asks for a workers.dev subdomaindash.cloudflare.com → Workers & Pages → pick a subdomain, then rerun.
Calls start with a Twilio "trial account" messageThe account isn't upgraded yet. Billing → Upgrade ($20).
The test text never arrives, but calls workSome Canadian numbers need SMS registration. Twilio Console → Monitor → Logs → Messaging shows the reason. Calls keep working either way. Send me the error code (not your keys) and I'll sort it out.
The phone doesn't ringCheck the Voice geo permission (Canada on), Do Not Disturb, and that the number is saved as Agent Bus. Run notify.py phone status.
A key might have leakedReset the Auth Token in Twilio, then rerun notify.py setup twilio. For the PC's own token, run notify.py setup gateway --rotate.

Where your keys live

  • Twilio SID, Auth Token, both phone numbers: only in Cloudflare (encrypted). Never on the PC or in git.
  • The PC's gateway token: in notifications\config.json, which git ignores. It can only alert you.
  • The planner token: only in Cloudflare and the planner server's env.
  • The gateway only ever dials your number, and every Twilio request is signature-checked.
