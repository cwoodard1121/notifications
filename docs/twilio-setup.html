Twilio → planner phone calls

About 10 minutes. Everything else is already live. Calls go server → Twilio → your phone, so they work with your PC off.

  1. Sign up The sign-up page is already open in Chrome (login.twilio.com/u/signup). Click Sign up with Google and pick your Gmail. That's the fastest way.
  2. Verify your cell Enter your phone number, then type the SMS code. This makes your cell a "verified" number, which a trial account is allowed to call.
  3. Onboarding questions Answer anything, e.g. Product: Voice · Goal: Alerts & notifications · Build: With code · Language: Python. Then Get started.
  4. Copy your 2 keys On console.twilio.com home, scroll to the Account Info box:
    • Account SID (starts with AC), using the copy icon
    • Auth Token: click Show, then copy
    Don't paste these anywhere except the next step.
  5. Run setup (PowerShell) 
    cd C:\Users\camer\Desktop\Projects\notifications
python notify.py setup twilio
    It asks for: SID (paste) → Auth Token (paste; nothing shows, that's normal) → buy a 519/226/548 number? y → your cell, e.g. +15195550123.
  6. Test call 
    python notify.py phone test --call
    Your phone rings. On a trial account you'll first hear a Twilio notice, so press any key. Then press 1. The terminal prints It works.
  7. Make it ring through Save the Twilio number as a contact named Planner, and allow it through Do Not Disturb / Focus.

Optional: upgrade (removes the trial notice)

Console top bar → Upgrade account → add a card → prepay US$20. Turn on a low-balance alert under Billing. It costs about US$3–5 a month; the number is ~US$1.15/mo.

What a call sounds like

"Yo, you have to lock in on this now." Then what you planned, in plain words, then:
1 on it · 2 snooze 10 min · 3 repeat · 9 already done (ticks the todo)

When it calls

  • Only for things you turn on: 📞 Call me on a todo or block, Call me at…, or ask the planner AI.
