Finish Twilio: about 5 minutes

Calls go server → Twilio → your cell, so they work with your PC off.

✓ Done already: Twilio account created ($15.50 trial credit) · your cell is verified · gateway + planner wired up.
Two numbers, two jobs:
  • Your cell (already verified) is the number that gets called. ✔
  • A Twilio number is the number that makes the call. You don't have one yet. The setup below gets it, paid from the trial credit (about $1.15/mo).
A phone can't call itself, which is why you need the second number. Ignore Twilio's "Get a phone number" card; step 3 does it for you.
  1. Open your keys console.twilio.com → Account Dashboard (top left) → scroll down to Account Info.
  2. Open PowerShell and run 
    cd C:\Users\camer\Desktop\Projects\notifications
python notify.py setup twilio
  3. Answer its 4 questions
    • Account SID: click the copy icon next to it, then right-click to paste in PowerShell.
    • Auth Token: click the copy icon next to the dots, then paste. Nothing shows on screen; that's normal. Press Enter.
    • Buy a 519/226/548 number? Type y.
    • Your cell: type your own number, e.g. +14375551234.
  4. Test call 
    python notify.py phone test --call
    Your phone rings. Twilio plays a trial notice first, so press any key. Then press 1. The terminal prints It works.
  5. Save the contact Save the new Twilio number (the setup prints it) as Planner, and allow it through Do Not Disturb.

If buying the number fails

Console → Phone Numbers → Manage → Buy a number → Country Canada, tick Voice → Search → Buy on any 519/226/548 number. Then run step 2 again; it reuses that number.
